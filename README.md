# PixelZone (beta)

Sitio web de portafolio sobre videojuegos, hecho con HTML, CSS, JavaScript y Bootstrap 5.

## Páginas
- `index.html` – inicio: carrusel, listas ordenadas y no ordenadas, alertas
- `noticias.html` – artículos con modal "Leer más"
- `enlaces.html` – iFrames de YouTube y Google Maps
- `contacto.html` – botón `mailto`, formulario con validación y modal

## Tecnologías
HTML5 · CSS3 (`css/styles.css`) · JavaScript (`js/main.js`) · Bootstrap 5.3 · Bootstrap Icons · Google Fonts (Press Start 2P, Poppins) · GitHub Pages

## Estado de la beta
Hecho: navegación, carrusel, modo oscuro, modal de privacidad, contacto, iFrames.
Pendiente: más artículos, buscador de juegos, imágenes reales.

## Publicar en GitHub Pages
1. Sube esta carpeta a un repositorio de GitHub.
2. En el repositorio: **Settings → Pages → Branch: main / root → Save**.
3. La página queda en `https://TU-USUARIO.github.io/NOMBRE-REPO/`.
